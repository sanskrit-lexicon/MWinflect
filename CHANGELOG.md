## [0.1.0] - 2026-06-30

### Added

- Initial release of MWinflect — a Sanskrit Lexicon processing tool for generating declensions and conjugations for words in the MW1899 dictionary
- Nominal declension support (`nominals/pydecl`) for Sanskrit nominal stems
- Analysis framework (`nominals/pysanskritv2`) for stem models and inflection patterns
- SQLite database schema and tables (`sqlite/`) for storing inflection data
- Python 3 scripts for declension computation across multiple stem types
- Support for irregular forms and pronoun declensions
